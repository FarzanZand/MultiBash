# MultiBash

Online co-op (1–4 players) horde survivor in the spirit of *Megabonk* / *Vampire Survivors*.
Unity 6 (URP) + Photon Fusion 2 (Host mode). All art and audio are generated by scripts in `Tools/`.

**Look:** low-poly models with chunky pixel textures (custom `MultiBash/PixelLit` shader), pixel sky, terrain
with plateaus/cliffs/ramps, castle walls, ruins and props, pixel UI (Silkscreen font, metal-framed windows).
**Run:** 10 minutes of swarms (skeletons, slimes, bats, archers, bomb shrooms, golems; magma slimes and
fire imps on the volcano). Elites wear crowns and drop chests, three bosses per run, charge shrines,
10 weapons, 16 powerups, crits, downed/revive co-op.
**Maps:** *The Keep* (castle ruins) and *Molten Caldera* (volcano with lava rivers that burn).
The host picks the map in the lobby.

## Play it

### With a friend (online)
1. Build (see below) and zip the whole `Builds/Windows/` folder. Send it to your friend.
2. Both run `MultiBash.exe`, type a name.
3. One of you clicks **HOST PARTY**. The lobby shows a **room code** like `K7QX2-eu` → press **COPY** and send it.
4. The other pastes it into the code box and clicks **JOIN**.
5. Pick heroes, the friend presses **READY**, the host presses **START RUN**.

> The `-eu` part is the Photon region. It makes sure you both connect to the same server even if you live in different countries. Always share the full code.

**QUICK JOIN** joins any open party (or creates one). **PLAY SOLO** works offline.

### Controls
| Action | Keyboard / Mouse | Gamepad |
|---|---|---|
| Move | WASD | Left stick |
| Camera | Mouse (scroll = zoom) | Right stick |

**Tech:** slide, then jump while sliding → you keep the slide speed in the air (≈45% faster). Chain it to outrun the horde.

## Test multiplayer on one PC

**Option A (fastest):** build once, then
- Run the build and **HOST PARTY**.
- In the Unity Editor press Play in `Scenes/MainMenu`, paste the code and **JOIN** (or the other way round).
- The editor keeps simulating in the background (menu *MultiBash ▸ Keep Playing In Background*).

**Option B:** run the build twice (it allows multiple instances).

**Command line** (handy for quick tests):
```
MultiBash.exe -name Bob -character 2 -host
MultiBash.exe -name Amy -character 0 -join K7QX2-eu
```
`-autopilot` lets a bot play (see Dev cheats).

### Make a build
*File ▸ Build Profiles ▸ Windows ▸ Build* → choose `Builds/Windows`. Scenes are already in the build list (MainMenu, Lobby, Game).

### Photon Fusion SDK and App ID (not in this repo)
The Photon Fusion 2 SDK (`Assets/Photon/`) and the App ID are not committed. To open the project from a fresh clone:
1. Import **Photon Fusion 2** (Unity Asset Store or [photonengine.com](https://www.photonengine.com/fusion)) into the project. It lands in `Assets/Photon/`.
2. Create a free Fusion app in the Photon dashboard and paste its App ID in *Tools ▸ Fusion ▸ Realtime Settings ▸ App Id Fusion*.
3. Run *MultiBash ▸ Setup ▸ Build Everything*.

Players of a build do **not** need an account: the App ID is baked into the build.

### The Content Browser
*MultiBash ▸ Content Browser* shows every hero, weapon, powerup and enemy with an inline editor
and a **Create new** button. New assets are picked up automatically.

### Add a new enemy (no code)
1. Duplicate `Content/Enemies/Skeleton` (folder) → rename.
2. In the new prefab swap the model under `Visual` (models with parts named Body/ArmL/ArmR/LegL/LegR get walk animation for free; anything else squashes & stretches like a slime).
3. Point the new EnemyDefinition's **Prefab** at the new prefab, tune the numbers.
4. Add it to `Waves/DefaultRun` or `Waves/VolcanoRun` (an entry or a burst). *MultiBash ▸ Refresh Database*. Done.

### Add a new map
1. Build a scene (copy `Scenes/Volcano.unity` or look at `MultiBashSetup.Volcano.cs` for a generated one). It needs a
   Terrain, a GameManager (NetworkObject), FxManager, CameraRig and HUD. Add it to Build Settings.
2. *Create ▸ MultiBash ▸ Map*: set the scene name, a wave asset, music, accent color, preview sprite, difficulty.
3. Point the scene's GameManager **Map** field at it. *MultiBash ▸ Refresh Database*: it shows up in the lobby picker.
4. Optional lava: a plane with `M_Lava` and a `LavaZone` component at the lava height.

### Add a weapon / powerup / hero
Right-click in the folder ▸ *Create ▸ MultiBash ▸ Weapon / Powerup / Character* (or use the Content Browser), fill it in, Refresh Database.
Weapons pick one of six behaviors (MeleeArc, Projectile, Chain, Lobbed, Orbit, Aura). A brand-new behavior = one new case in `Scripts/Combat/WeaponSystem.cs`.

### Regenerate art / audio
```
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b -P Tools/Blender/generate_models.py
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b -P Tools/Blender/render_previews.py
python Tools/Textures/generate_textures.py
python Tools/Audio/generate_audio.py
```
Change a color in `Tools/palette.json`, re-run the texture script, and every model using it updates.

### Setup tool
*MultiBash ▸ Setup ▸ Build Everything* recreates anything missing (never overwrites your edits).
*Reset Content Data To Defaults* / *Rebuild Scenes Only* / *Rebuild Everything (overwrite)* regenerate from code.

## Art pipeline notes
- Every model uses one material (`Art/Materials/M_Palette`) and the palette texture. Each palette color
  also picks a **pixel pattern** (noise / brick / leaves / grain / glow / flat) via `Tools/palette.json`.
  `glow` colors are emissive and bloom (crystals, runes, eyes, fire).
- Terrain is generated by the setup tool (`MultiBashSetup.Scenes.cs > ArenaHeight`): edit the `Plateaus`
  list to move hills/plateaus/ramps, then *MultiBash > Setup > Rebuild Scenes Only*.

## How the networking works (short)
- **Host mode:** the host simulates enemies, damage, XP, drops; clients predict their own movement.
- Enemies and pickups are network objects; weapon effects (arrows, slashes, lightning, flasks) are RPC'd visuals, so hundreds of effects cost almost no bandwidth.
- Players' lobby choices live on `PlayerData`, which survives scene changes. Late joiners spawn into a running game and get catch-up level-ups.
